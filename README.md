## Usability Evaluation and Improved Wireframe

This repository contains my Week 1 practical work for Human-Computer Interaction (HCI).

## Practical Tasks

### 1. Usability Evaluation
Evaluated the UAF Student Web Portal login page and identified seven usability issues using Nielsen's usability heuristics.

### 2. Improved Design Wireframe
Created an improved UAF Portal Login Page wireframe using Figma.

The design includes:
- Desktop view – Student
- Mobile view – Student
- Mobile view – International Student
- Faculty & Staff views
- Tablet view – Faculty & Staff

### 3. Design Improvements
- Improved login form visibility.
- Clear logo and page title.
- Correct AGNO label.
- Improved text and colour consistency.
- Helpful input hints.
- Foreign student option.
- Clear login interface.
